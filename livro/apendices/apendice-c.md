Lei de Ohm e Potência

V=I×R
I=V/R
R=V/I
P=V×I
P = I² × R
P = V² / R

Associação de Resistores

Série: R_total = R₁ + R₂ + R₃ + ...
Paralelo: 1/R_total = 1/R₁ + 1/R₂ + 1/R₃ + ...
2 em Paralelo: R_total = (R₁ × R₂) / (R₁ + R₂)

Divisor de Tensão

V_saída = V_entrada × (R₂ / (R₁ + R₂))

Constante de Tempo RC

τ=R×C

Conversões de Unidades

   Tensão: 1V = 1000mV = 1.000.000μV

   Corrente: 1A = 1000mA = 1.000.000μA

   Resistência: 1kΩ = 1000Ω, 1MΩ = 1.000.000Ω

   Capacitância: 1F = 1.000.000μF = 1.000.000.000nF =
    1.000.000.000.000pF
