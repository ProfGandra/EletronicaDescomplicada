# Referências para as imagens

Esta pasta é **exclusiva da documentação iconográfica** de *Eletrônica DC Descomplicada*.

No manuscrito de 2025, depois dos seis apêndices, aparecem **19 blocos intitulados CAPÍTULO 1 a CAPÍTULO 19**, contendo descrições e instruções para a criação das figuras. Esses blocos **não integram a sequência didática de 23 capítulos** e devem ser mantidos à parte.

## Convenção

- `bloco-01` a `bloco-19`: correspondem à numeração da seção de referências do **manuscrito original**, não à nova numeração editorial.
- Ao produzir as figuras, conferir o texto, as ligações, as unidades e as legendas antes da inserção.
- Após a renumeração dos capítulos, atualizar todas as chamadas de figura no texto principal.

**Situação:** estrutura separada no repositório. Os textos completos das referências ainda precisam ser transferidos dos arquivos preparados para esta pasta.
